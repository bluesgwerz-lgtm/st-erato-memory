# Erato Memory

为 Erato 预设定制的 SillyTavern 长期记忆扩展。手机 / 电脑双端可用。

- 逐楼把剧情整理成结构化记忆条目（副 API 摘要，任意 OpenAI 兼容接口，可拉取模型列表选择）
- 与 Erato 的恒定窗口正则组严格对齐：正文被窗口剥离之后，由记忆条目接管
- 总结完成后自动隐藏已总结的旧楼层，只保留最近 N 楼可见（可逆，默认开），长聊天在手机上不再卡
- S/A/B/C 四级记忆 + 手动钉选，按楼层衰减
- 记忆随聊天文件保存；两端连同一个酒馆实例时自动共享
- 手机优先：半透明可拖动的悬浮球（角标显示待总结楼数）+ 魔杖菜单入口；面板单列，一键「总结前文」跑到底

**当前版本 v0.2.1**：入库 + 顺序注入 + 隐藏已总结楼层 + 悬浮球 + 面板重排（注入预览、手动新增、提示词模板可编辑、斜杠命令）。人物物件档案、按日大纲、向量召回见 [DESIGN.md](DESIGN.md) 的分期。

## 安装

酒馆 → 扩展面板 → 安装扩展 → 填入本仓库地址：

```
https://github.com/bluesgwerz-lgtm/st-erato-memory
```

## 使用

1. 打开面板：点屏幕上的 🧠 悬浮球（可拖动，松手吸边），或输入框左侧魔杖菜单里的「记忆面板」。首次未配 API 会直接落到设置页。
2. 填副 API 地址（如 `https://api.example.com/v1`）和密钥，点「拉取模型」选模型；接口不支持列模型时在「模型名」里手填。点「测试连接」确认可用。
3. 旧聊天：面板顶部会显示「待总结 N」，点「总结前文」一次跑到底（可中途停止，带进度）。魔杖菜单里的「总结前文」不开面板也能跑。
4. 新聊天：正常聊即可，每楼 AI 回复沉到第 3 层之后自动总结。
5. 总结完成后，除最近 6 楼外的已总结楼层会被隐藏（酒馆的「隐藏消息」，仍可在聊天里看到，只是不进提示词）。「更多 → 取消隐藏」可一键恢复；设置里可关掉或改保留楼数。
6. 时间线里：点等级块循环改等级，长按钉为 S 级；点卡片展开可编辑、重摘要、跳到该楼。「更多 → 手动新增」可补录遗漏的事。
7. 「本轮注入预览」分区能直接看到这轮塞给模型的记忆原文，不用开提示词查看器。

斜杠命令（可接进 QuickReply）：`/em-panel` 开面板 · `/em-summarize` 总结前文 · `/em-pin 楼层号` 钉/取消钉 · `/em-note 文字` 手动记一条。

## 与预设的配合

- 「正文窗口」设置默认 6，与预设正则 `6🌸发送最后4层正文` 的 minDepth 一致；两边改要一起改。开着「隐藏已总结」时，可见楼层通常都在窗口内，记忆块落在它们前面。
- 副 API 的选择决定 NSFW 楼层能否入库；拒答会在面板顶部红条显示，可换模型后「更多 → 重试失败」。
- 提示词模板可在设置「提示词」组里查看并修改（留空即默认）。
