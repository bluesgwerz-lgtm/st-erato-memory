# Erato Memory

为 Erato 预设定制的 SillyTavern 长期记忆扩展。

- 逐楼把剧情整理成结构化记忆条目（副 API 摘要，可配任意 OpenAI 兼容接口）
- 与 Erato 的恒定窗口正则组严格对齐：正文被窗口剥离之后，由记忆条目接管
- S/A/B/C 四级记忆 + 手动钉选，按楼层衰减，非破坏归档
- 记忆随聊天文件保存，手机 / 电脑双端可用
- 手机优先的记忆面板：查看、编辑、改等级、钉选、重摘要

**状态：设计阶段。** 完整设计见 [DESIGN.md](DESIGN.md)。

## 安装

扩展面板 → 安装扩展 → 填入本仓库地址。

## 使用

1. 扩展设置里填写副 API 地址、密钥、模型，点「测试连接」。
2. 正常聊天即可，条目自动入库；点顶栏图标打开记忆面板。
