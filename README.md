# Erato Memory

为 Erato 预设定制的 SillyTavern 长期记忆扩展。手机 / 电脑双端可用。

- 按**段**总结：攒够 N 楼（默认 10）自动把这一段交给副 API 一次总结，按事件切成记忆条目（一场争吵、一次亲密不再拆成十条），一次调用最多吃 W 楼（默认 20，可开到 100）
- 同一次调用顺手维护**人物志 / 物件 / 主角关系现状**：配角的身份、与双方的关系、立场、现状、知情范围，物件在谁手里；{{char}} 对 {{user}} 的态度一行随剧情更新
- 与 Erato 的恒定窗口正则组严格对齐：正文被窗口剥离之后，由记忆条目接管
- 总结完成后自动隐藏已总结的旧楼层，只保留最近 N 楼可见（可逆，默认开），长聊天在手机上不再卡
- S/A/B/C 四级记忆 + 手动钉选，按楼层衰减；人物志按「最近几楼提到谁」决定谁出完整档案
- 副 API 拒答或输出损坏时自动把段落对半拆分重试，不会一次废掉几十楼
- 记忆随聊天文件保存；两端连同一个酒馆实例时自动共享
- 手机优先：半透明可拖动的悬浮球（角标显示待总结楼数）+ 魔杖菜单入口；面板单列，一键「总结到当前」跑到底

**当前版本 v0.3.0**：窗口制入库 + 人物志/物件/关系现状 + 顺序注入 + 隐藏已总结楼层 + 悬浮球 + 面板（注入预览、手动新增、提示词模板可编辑、斜杠命令）。旧版（逐楼）数据自动迁移。设计与分期见 [DESIGN.md](DESIGN.md)。

## 安装

酒馆 → 扩展面板 → 安装扩展 → 填入本仓库地址：

```
https://github.com/bluesgwerz-lgtm/st-erato-memory
```

## 使用

1. 打开面板：点屏幕上的 🧠 悬浮球（可拖动，松手吸边），或输入框左侧魔杖菜单里的「记忆面板」。首次未配 API 会直接落到设置页。
2. 填副 API 地址（如 `https://api.example.com/v1`）和密钥，点「拉取模型」选模型；接口不支持列模型时在「模型名」里手填。点「测试连接」确认可用。
3. 设置页「总结节奏」：
   - **自动总结**：手动 / 每 10 / 15 / 20 楼 / 自定义。攒够这么多新楼就自动总结一次；选「手动」则只在点按钮时总结。
   - **单次总结最大楼层**：20 / 30 / 50 / 100 / 自定义。一次副 API 调用最多吃多少楼。越大越省钱也越粗：日常 20–30，清不在乎细节的老积压再开到 50–100。
   - **单次最大字数**（默认 6 万字）：材料超过这个数自动再切一段，按副模型的上下文大小调。
4. 旧聊天：面板顶部会显示「待总结 N 楼」，点「总结到当前」，确认框会报大约几次调用，然后一次跑到底（可中途停止，带进度）。魔杖菜单里的「总结到当前」不开面板也能跑。
5. 新聊天：正常聊即可，攒够设定楼数后自动总结（最新两楼留着，等它们沉下去再入库）。点「总结到当前」则连最新楼一起总结。
6. 总结完成后，除最近 6 楼外的已总结楼层会被隐藏（酒馆的「隐藏消息」，仍可在聊天里看到，只是不进提示词）。「更多 → 取消隐藏」可一键恢复；设置里可关掉或改保留楼数。
7. 「人物与物件」分区：关系现状一行可直接改；点人物/物件卡展开可改名字、别称、各字段或删除；值旁边的 `#楼层` 可点跳过去核对。
8. 时间线里：点等级块循环改等级，长按钉为 S 级；点卡片展开可编辑、重跑本段、跳到该楼。失败/拒答的段落显示在时间线顶部，可重试、拆半重试或标为不入库。「更多 → 手动新增」可补录遗漏的事。
9. 「本轮注入预览」分区能直接看到这轮塞给模型的记忆原文，不用开提示词查看器。

斜杠命令（可接进 QuickReply）：`/em-panel` 开面板 · `/em-summarize` 总结到当前 · `/em-pin 楼层号` 钉/取消钉该楼所在的记忆 · `/em-note 文字` 手动记一条。

## 与预设的配合

- 「正文窗口」设置默认 6，与预设正则 `6🌸发送最后4层正文` 的 minDepth 一致；两边改要一起改。开着「隐藏已总结」时，可见楼层通常都在窗口内，记忆块落在它们前面。
- 副 API 的选择决定 NSFW 楼层能否入库；拒答会先自动拆半重试，仍失败的段落在面板顶部红条显示，可换模型后「更多 → 重试失败」。
- 副 API 的「回复上限」默认 4000 token：一段最多 20 楼会产出十来条事件加档案，太小会截断（截断会触发拆半）。
- 提示词模板可在设置「提示词」组里查看并修改（留空即默认；必须含 `{{material}}`）。
