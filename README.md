# Erato Memory

为 Erato 预设定制的 SillyTavern 长期记忆扩展。手机 / 电脑双端可用。

- 逐楼把剧情整理成结构化记忆条目（副 API 摘要，任意 OpenAI 兼容接口）
- 与 Erato 的恒定窗口正则组严格对齐：正文被窗口剥离之后，由记忆条目接管
- S/A/B/C 四级记忆 + 手动钉选，按楼层衰减
- 记忆随聊天文件保存；两端连同一个酒馆实例时自动共享
- 手机优先的记忆面板：查看、编辑、改等级、钉选、重摘要、导出导入

**当前版本 v0.1（MVP）**：入库 + 顺序注入 + 面板。归档合并、备用模型、向量召回见 [DESIGN.md](DESIGN.md) 的分期。

## 安装

酒馆 → 扩展面板 → 安装扩展 → 填入本仓库地址：

```
https://github.com/bluesgwerz-lgtm/st-erato-memory
```

## 使用

1. 扩展设置里找到「🧠 Erato Memory」，填写副 API 地址（如 `https://api.example.com/v1`）、密钥、模型名，点「测试连接」。
2. 正常聊天即可。每楼 AI 回复沉到第 3 层之后自动入库；正文被预设窗口剥掉的楼层，其条目会按时间顺序注入到上下文 depth 6。
3. 顶栏 🧠 图标打开记忆面板：点等级块循环改等级，长按钉为 S 级；点卡片展开可编辑、重摘要、跳到该楼。

## 与预设的配合

- 「正文窗口」设置默认 6，与预设正则 `6🌸发送最后4层正文` 的 minDepth 一致；两边改要一起改。
- 插件跑稳后可把预设正则 `5🌸仅发送最后10轮摘要` 的 minDepth 从 20 改为 6，省掉中间楼层的 recap。
- 副 API 的选择决定 NSFW 楼层能否入库；拒答会在面板顶部红条显示，可换模型后「重试失败」。
